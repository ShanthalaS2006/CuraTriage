# 🚑 Transforming Emergency Healthcare with AI

CuraTriage AI is an intelligent healthcare assistant designed to help hospitals prioritize patients efficiently using AI-driven symptom analysis and smart triage recommendations.

Our solution improves:
- ⚡ Emergency response time
- 🧠 AI-assisted diagnosis support
- 🏥 Hospital workflow management
- ⏳ Patient prioritization efficiency

# ⚡ Run Locally

## 📌 Prerequisites

Make sure you have installed:

- Node.js
- npm

---

## 🔧 Installation

```bash
# Clone the repository
git clone https://github.com/your-username/CuraTriage.git

# Navigate into project folder
cd CuraTriage

# Install dependencies
npm install
```

---

# 🔑 Environment Variables

Create a `.env.local` file in the root directory and add:

```env
GEMINI_API_KEY=your_api_key_here
```

---

# ▶️ Start Development Server

```bash
npm run dev
```

Application runs on:

```bash
http://localhost:3000
```
