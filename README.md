# 🏥 CuraTriage AI  
### AI-Powered Smart Hospital Triage System

🚑 Transforming emergency healthcare with Artificial Intelligence.

---

## 🌟 Overview

CuraTriage AI is an intelligent healthcare assistant designed to help hospitals prioritize patients efficiently using AI-driven symptom analysis and triage recommendations.

---

## ✨ Features

✅ AI-based patient symptom analysis  
✅ Smart triage prioritization  
✅ Fast and responsive UI  
✅ Real-time recommendations  
✅ Secure and scalable architecture

## ⚡ Run Locally

### 📌 Prerequisites
- Node.js
- npm

### 🔧 Installation

```bash
git clone https://github.com/your-username/CuraTriage.git

cd CuraTriage

npm install
```

---

## 🔑 Environment Variables

Create a `.env.local` file:

```env
GEMINI_API_KEY=your_api_key_here
```

---

## ▶️ Start Development Server

```bash
npm run dev
```
